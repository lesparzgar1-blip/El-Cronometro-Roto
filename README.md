# El Cronómetro Roto

## Descripción
El Cronómetro Roto es un proyecto desarrollado en C# que simula la gestión de una empresa de escape room.

El programa permite registrar contrataciones de expediciones, seleccionar servicios adicionales, elegir modalidades, calcular descuentos, gestionar pagos y consultar un resumen de la actividad económica.

## Expediciones disponibles
- El Santuario Olvidado.
- El Templo del Tiempo.
- La Cámara de los Sabios.

## Tecnologías utilizadas
- Lenguaje de programación: C#.
- Entorno de desarrollo: Visual Studio Code.
- Plataforma: .NET.

## Cómo ejecutar el programa
1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar el siguiente comando en la terminal:

dotnet run
